## Python SDK 0.1.6

[`limitguard` 0.1.6](https://pypi.org/project/limitguard/) is on PyPI:

- `verify_lead` and `agent_check` call [Lead Verify](/changelog/2026-10-03) and the agent
  wallet check.
- `limitguard.integrations.langchain` and `limitguard.integrations.crewai` wrap the checks
  as LangChain and CrewAI tools, with a spend cap that is on by default.

```bash
pip install --upgrade limitguard
```
