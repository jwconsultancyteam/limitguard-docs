All prices are in USDC. Pay per API call via the [x402 protocol](/x402-protocol), or hold a paid-tier [API key](/authentication) with a prepaid balance that each priced call is debited from.

**What it is:** LimitGuard is a KYB, sanctions/PEP and entity-trust API for AI agents and developers: it checks a company against business registers (KVK, KBO/CBE), VIES VAT, OpenSanctions, its domain and country risk, is paid per call with x402 (USDC) or an API key, is also served as an MCP server, and is hosted in the EU.

**Start here:** Free sandbox key, no wallet. $0.65-0.85 fresh for entity and risk checks ($1.50 KYB); $0.10 cached ($0.25 KYB) when available.

## Tiered Pricing

Four core endpoints support three quality tiers. Select with the `X-Response-Quality` header (default: `fresh`).

| Endpoint | Cached | Fresh (default) | Enhanced |
|----------|--------|-----------------|----------|
| `POST /v1/entity/check` | $0.10 | $0.85 | $1.50 |
| `POST /v1/risk/score` | $0.10 | $0.65 | $1.00 |
| `POST /v1/reputation/score` | $0.10 | $0.65 | $1.00 |
| `POST /v1/kyb/check` | $0.25 | $1.50 | $3.00 |

### Quality Tier Definitions

<AccordionGroup>
  <Accordion title="Cached — Cheapest" icon="bolt">
    Return Redis-cached result if available. Use when freshness isn't critical and you want the lowest cost. Set `X-Response-Quality: cached`.
  </Accordion>
  <Accordion title="Fresh — Default" icon="rotate">
    Always run full data source fan-out. This is the default behavior when no header is sent. Set `X-Response-Quality: fresh`.
  </Accordion>
  <Accordion title="Enhanced — Most Comprehensive" icon="star">
    Full fan-out plus premium data sources. Use for high-value transactions requiring maximum confidence. Set `X-Response-Quality: enhanced`.
  </Accordion>
</AccordionGroup>

## MCP Tool Endpoints

The [5 MCP tools](/guides/ai-agent-integration#mcp-model-context-protocol) are **not** free, even though they're callable as native LLM tools. Where a tool mirrors a tiered REST endpoint it costs the same as that endpoint's `fresh` tier; the remaining three are flat-priced:

| Endpoint | Tool | Price |
|----------|------|-------|
| `POST /v1/mcp/check-entity` | `check_entity` | $0.85 |
| `POST /v1/mcp/risk-score` | `get_risk_score` | $0.65 |
| `POST /v1/mcp/check-agent` | `check_agent` | $0.00 |
| `POST /v1/mcp/trust-score` | `get_trust_score` | $0.00 |
| `POST /v1/mcp/verify-wallet` | `verify_wallet` | $0.00 |

<Note>
  The `Endpoint` column shows the REST transport path. MCP clients invoke these by tool name with the arguments declared in the [MCP manifest](/guides/ai-agent-integration#mcp-model-context-protocol). `verify_wallet` is the only tool exposed over `GET`, so its `wallet_address` and `chain_id` arguments are not sent as a JSON body.
</Note>

## API Key Tier Upgrades

Pay via x402 to top up an API key's prepaid balance (`POST /v1/keys/upgrade/{tier}` or `POST /v1/keys/topup/{usd}`). This is the only case where x402 payment is required even if you already hold an API key — see [Authentication](/authentication#api-key-authentication) for the full tier ladder. Quotas reset on the first day of each calendar month (UTC).

| Endpoint | Price | Unlocks |
|----------|-------|---------|
| `POST /v1/keys/upgrade/indie` | $29 | 1,000 calls/mo |
| `POST /v1/keys/upgrade/starter` | $99 | 10,000 calls/mo |
| `POST /v1/keys/upgrade/growth` | $299 | 50,000 calls/mo |
| `POST /v1/keys/upgrade/pro` | $999 | 250,000 calls/mo |

## Dynamic Pricing

Pricing can adjust based on volume. Query current prices:

```bash
# All endpoint prices with volume discount
curl "https://api.limitguard.ai/v1/sales/pricing?monthly_calls=1000"

# Specific endpoint price
curl "https://api.limitguard.ai/v1/sales/pricing/v1%2Fentity%2Fcheck?monthly_calls=1000"
```

Volume discounts are applied automatically based on your `monthly_calls` parameter.
