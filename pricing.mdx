All prices are in USDC. Pay per API call via the [x402 protocol](/x402-protocol), or hold a paid-tier [API key](/authentication) with a prepaid balance that each priced call is debited from.

  The dashboard at [dashboard.limitguard.ai](https://dashboard.limitguard.ai/?utm_source=docs&utm_medium=docs&utm_campaign=signup&utm_content=pricing) is priced separately, in euros: per lead, per company check with a PDF report, and optional monthly or yearly plans that include credit. See [limitguard.ai/pricing](https://limitguard.ai/pricing/?utm_source=docs&utm_medium=docs&utm_campaign=pricing&utm_content=pricing).

**What it is:** Limitguard is a lead validation service for lead generation agencies, B2B marketing and sales teams: it checks the company behind each lead against official business registers (full coverage in the Netherlands and Belgium), EU VAT and sanctions lists, with website age in the company check, and returns proceed, review or block with the source on every line. Developers and AI agents can use its HTTP API, MCP server and A2A service, hosted in the EU.

**Start here:** Free sandbox key, no wallet. The sandbox covers entity, risk and KYB checks; Lead Verify and the agent check need a live key or an x402 payment. Paid by x402: Lead Verify \$0.05 per lead and agent check \$0.005 per wallet; entity check and KYB \$0.29 and risk score \$0.25 fresh, \$0.11 cached (\$0.25 KYB) when available; report \$0.55; sanctions and wallet screens \$0.005; other routes at the account price. API keys, the dashboard and the Claude connector pay the account prices: Lead Verify \$0.27 per lead and agent check \$0.75 per wallet; \$0.11-1.85 per call; entity and risk checks \$0.88-1.05 fresh (\$1.50 KYB), \$0.11 cached (\$0.25 KYB) when available.

## Agent prices (x402)

An x402 payment pays the agent price: REST, A2A with x402, and MCP pay-per-call on `/mcp`. An API key, the dashboard and the Claude connector pay the account price, from prepaid credit. A route not listed here costs its account price with x402 too.

The official x402 SDKs refuse a payment above one dollar by default (`maxAmountPerPayment`). That default covers every agent price. Raise it only for the deep-check `enhanced` and `credit` tiers and for the `/v1/keys/upgrade/*` and `/v1/keys/topup/*` purchases.

## Tiered Pricing

Four core endpoints sell two quality tiers. Select with the `X-Response-Quality` header (default: `fresh`).

| Endpoint | Cached | Fresh (default) |
|----------|--------|-----------------|
| `POST /v1/entity/check` | $0.11 | $1.05 |
| `POST /v1/risk/score` | $0.11 | $0.90 |
| `POST /v1/reputation/score` | $0.11 | $0.90 |
| `POST /v1/kyb/check` | $0.25 | $1.50 |

`enhanced` was retired on these four endpoints on 2026-09-24: it ran the same sources as `fresh`, so `X-Response-Quality: enhanced` is now quoted, charged and served at the `fresh` price, and the 402 body's `info.note` says so. `POST /v1/entity/deep-check` keeps its own tiers (see [x402 Protocol](/x402-protocol)).

### Quality Tier Definitions

<AccordionGroup>
  <Accordion title="Cached (cheapest)" icon="bolt">
    Return Redis-cached result if available. Use when freshness isn't critical and you want the lowest cost. Set `X-Response-Quality: cached`.
  </Accordion>
  <Accordion title="Fresh (default)" icon="rotate">
    Always run full data source fan-out. This is the default behavior when no header is sent. Set `X-Response-Quality: fresh`.
  </Accordion>
</AccordionGroup>

## Flat-Priced Endpoints

These endpoints have a single price regardless of quality tier:

| Endpoint | Price |
|----------|-------|
| `POST /v1/leads/verify` | $0.27 |
| `POST /v1/agent/check` | $0.75 |
| `POST /v1/sanctions/screen` | $0.11 |
| `GET /v1/reputation/history/{entity_hash}` | $0.11 |
| `GET /v1/wallet/balance` | $0.11 |
| `GET /v1/compliance/alerts` | $0.11 |
| `GET /v1/compliance/readiness/{entity_id}` | $0.11 |
| `POST /v1/reports/entity` | $1.85 |

`POST /v1/reports/entity` builds a per-entity report from one real check: registry identity, sanctions and PEP screening, domain signals, risk score, up to 12 findings, a per-source status table (a source that did not answer is shown unavailable, never clean) and an evidence hash. Send identifiers or the `check_id` of an earlier report's check. Reading a stored report back with `GET /v1/reports/{report_id}` is free (`?format=pdf` for a PDF). Sandbox keys cannot create reports: they are built only from real checks.

### Deep check

`POST /v1/entity/deep-check` has no cached tier. Its default is `deep` (its `fresh` tier) and `extended` is its `enhanced` tier; where enabled, `credit` is a third tier.

| Endpoint | Fresh (default) | Enhanced |
|----------|-----------------|----------|
| `POST /v1/entity/deep-check` | $0.88 | $1.71 |

- `deep` (`fresh`): PEP and relative/close-associate matches from OpenSanctions, plus a Dutch Centraal Insolventieregister insolvency screen (NL only).
- `extended` (`enhanced`): the same, plus adverse media screening against a global news index.
- `credit` ($2.45, Italy only, available when enabled): the same as `deep`, plus an Italian credit report from Openapi.com.

## MCP Tool Endpoints

The [MCP tools](/guides/ai-agent-integration#mcp-model-context-protocol) are priced per call like the REST API. `check_entity` and `get_risk_score` cost the same as the `fresh` tier of the endpoint they mirror; `get_trust_score` (your own most recent stored score for an entity), `sanctions_preview` and `wallet_sanctions_preview` (a yes/no OFAC SDN check of a wallet address) are free; `verify_wallet` (the full wallet screen) costs \$0.11; `get_compliance_report`, `sanctions_screen`, `check_agent_wallet` and `verify_lead` are billed at the price of the REST endpoint they call (`POST /v1/reports/entity`, `POST /v1/sanctions/screen`, `POST /v1/agent/check` and `POST /v1/leads/verify`, in the tables above). `check_agent` is an unimplemented placeholder: \$0.00, and hidden from the MCP tool list. The REST mirrors:

| Endpoint | Tool | Price |
|----------|------|-------|
| `POST /v1/mcp/check-entity` | `check_entity` | $1.05 |
| `POST /v1/mcp/risk-score` | `get_risk_score` | $0.90 |
| `POST /v1/mcp/check-agent` | `check_agent` | $0.00 |
| `POST /v1/mcp/trust-score` | `get_trust_score` | $0.00 |
| `POST /v1/mcp/verify-wallet` | `verify_wallet` | $0.11 |

<Note>
  The `Endpoint` column shows the REST transport path. MCP clients invoke these by tool name with the arguments declared in the [MCP manifest](/guides/ai-agent-integration#mcp-model-context-protocol). Every REST mirror is a `POST` with a JSON body, `verify_wallet` included.
</Note>

## API Key Tier Upgrades

Pay via x402 to top up an API key's prepaid balance (`POST /v1/keys/upgrade/{tier}` or `POST /v1/keys/topup/{usd}`). This is the only case where x402 payment is required even if you already hold an API key. See [Authentication](/authentication#api-key-authentication) for the full tier ladder. The balance does not expire or reset. Each key also has a monthly call cap equal to its tier's limit in the table below. It resets at 00:00 UTC on the 1st; see [Rate Limits](/guides/rate-limits#monthly-cap-per-key).

API key top-ups (Indie, Starter, Growth, Pro in USD) are prepaid balances for the API; they are not the dashboard's monthly or yearly plans.

| Endpoint | Price | Rate limits |
|----------|-------|---------|
| `POST /v1/keys/upgrade/indie` | $29 | 30 / min, 1,000 / 24 h, 1,000 / month |
| `POST /v1/keys/upgrade/starter` | $99 | 60 / min, 10,000 / 24 h, 10,000 / month |
| `POST /v1/keys/upgrade/growth` | $299 | 120 / min, 50,000 / 24 h, 50,000 / month |
| `POST /v1/keys/upgrade/pro` | $999 | 300 / min, 250,000 / 24 h, 250,000 / month |
