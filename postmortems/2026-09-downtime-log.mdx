All times UTC.

| When | What |
|---|---|
| 2026-09-19 00:34 | Tracing backend upgraded. The API does not depend on it to serve requests and stayed up. |
| 2026-09-19 00:40:55 | Container engine upgrade on the API host starts. Every container on the host stops, including the API and the reverse proxy in front of it. |
| 2026-09-19 00:41:45 | All containers back and healthy. `api.limitguard.ai/health` returns 200. |

About 50 seconds of downtime. Requests in that window could not connect. Every service restarted from its existing data. The upgrade was run in the lowest-traffic hour.
